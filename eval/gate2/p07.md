## Candidates (2)

- **Preserving The Shape** [warn] — When a change is bolted onto an existing structure specifically to avoid disturbing it — because touching it would trigger a migration, recertification, or retraining cost — the new behavior inherits constraints it was never designed for, and the reason to avoid them becomes a reason not to fix them. TRIGGER: A change explicitly scoped to avoid touching an existing schema, interface, migration, or retraining/re-certification cost — phrases like "without changing the existing", "to avoid a migration", "keep it backward compatible" driving the design rather than following it.
- **Chesterton's Dead Code** [block] — Code that appears unused is often reachable through a path nobody has in mind — an old flag, a stale server, a legacy client — so removing the guard while leaving the code, or reusing its switch for a new meaning, arms a landmine that only fires under partial deployment. TRIGGER: A diff that deletes or repurposes a feature flag, retry, guard clause, or branch labeled unused/deprecated/legacy without explaining what originally set it.
