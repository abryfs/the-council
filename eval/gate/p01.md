# p01

**Prompt:**
> add a rate limiter to the /v1/invites endpoint. 20 per hour per team, return 429 with a retry-after header. use whatever's already in the middleware chain, don't pull in a new dep

_Context: Mid-build on an API, adding abuse protection before a small public beta_


## Candidates (8, ranked by lexical match)

- **Seat Pricing Punishes Adoption** [warn] — When a product's value rises with how many colleagues are on it but the price also rises per colleague, the buyer's rational move is to restrict the rollout — which starves the exact network effect the product depends on. The pricing model actively fights the product's mechanism, and the resulting low penetration reads to the team as weak demand. TRIGGER: A pricing page or spec charging per seat, per user, or per member for a product whose core value requires a whole team, or charging full price for read-only/viewer/observer roles.
- **Discoverability Mistaken For Absence** [note] — Users request features they cannot find, so a request queue reads as a gap list when it is often a findability report; building the requested thing a second time adds surface area without adding capability and makes the original even harder to find. TRIGGER: A ticket or spec proposes building a capability that may already exist somewhere in the product — "add a way to X," "users can't do Y" — without a check of whether X/Y already ships behind a menu, flag, or command.
- **Distributed Monolith** [warn] — Splitting a codebase into services that share a release cadence and shared libraries converts in-process function calls into network calls without decoupling deploys, so you pay partial-failure, latency, and operational cost while keeping every coupling you had. TRIGGER: A spec proposing a separate service, worker, repo, or deployable per entity/destination/integration, or a diff introducing an RPC boundary between two things that ship together.
- **Negative Unit Economics As Growth** [block] — Pricing below variable cost makes every additional user a larger loss, which inverts the normal relationship between traction and survival — the growth metrics look spectacular precisely while the company is dying faster. "We'll fix margins with scale" only works when marginal cost falls with volume, which it does not for pass-through goods. TRIGGER: A pricing proposal with unlimited/all-you-can-eat framing, a price below the per-user infrastructure or fulfillment cost, or copy promising to monetize later via ads, data, or upsell.
- **Chesterton's Dead Code** [block] — Code that appears unused is often reachable through a path nobody has in mind — an old flag, a stale server, a legacy client — so removing the guard while leaving the code, or reusing its switch for a new meaning, arms a landmine that only fires under partial deployment. TRIGGER: A diff that deletes or repurposes a feature flag, retry, guard clause, or branch labeled unused/deprecated/legacy without explaining what originally set it.
- **Relearning Tax Ignored** [warn] — In a product people use daily, the interface is a motor habit; moving things resets that habit for every existing user at once, so the cost is paid on day one by everyone while the benefit accrues slowly to newcomers who do not exist yet. The new-user gain almost never exceeds the aggregate relearning loss. TRIGGER: A spec reorganizes navigation, moves an existing feature to a new location, renames a primary action, or changes the information architecture of a product that already has habituated daily users.
- **Signifier Erasure** [warn] — Flattening removes borders, fills, and shadows — which are not decoration but the clickability cues users scan for — so the visual noise drops while the search cost rises; the page looks calmer in a screenshot and costs more per task in use. TRIGGER: A diff removes borders, background fills, underlines, or shadows from interactive elements, converts buttons to text/ghost buttons, or a spec asks to "make it cleaner / flatter / less chrome."
- **Single Channel Concentration** [warn] — A channel that supplies most of your users has a ceiling set by audience size and a decay curve set by fatigue and competitive entry, and both arrive without warning. Because the channel is working, nobody funds a second experiment until the first one flattens — at which point there is no runway to discover the replacement. TRIGGER: A growth model that extrapolates the current dominant channel's conversion rate forward, or a plan where one channel already supplies most users and no second-channel experiment is funded and dated.
